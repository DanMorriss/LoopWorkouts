# Progress

Built: last time on each rep step (PRG-1), personal bests on the workout summary (PRG-2), latest and best on the exercises list (PRG-3), progress on the exercise page (PRG-4), the muscles worked this week on the Progress page (PRG-6), the most rounds in a time limit (PRG-7), a bar per muscle group against the sets a week aimed for (PRG-8), a suggested next workout (PRG-9, on Today and the workout summary), a suggested next weight on each rep step (PRG-5), what to step up next time (PRG-10) and the muscles worked (PRG-11) on the workout summary, the time per week on the Progress page (PRG-12), the exercises done this week, with their new bests, on the Progress page (PRG-13), one kettlebell for a kettlebell workout, going up in reps to 20 and then to a heavier kettlebell (PRG-14), and stretches for the muscles a workout worked, on its summary (PRG-16). Builds on [exercises](exercises.md) and the sets in the [history](history.md).

## Stories

- **PRG-1** As a user, mid-workout, I want to see what I did last time on each rep step, so I know what to beat.
- **PRG-2** As a user I want to be told when I've set a personal best, when the workout finishes.
- **PRG-3** As a user I want a list of my exercises, each with its latest and best.
- **PRG-4** As a user I want a page per exercise with a chart over time, its bests and its recent sessions.
- **PRG-5** As a user I want the app to suggest the next weight to try, based on how my last sessions went.
- **PRG-6** As a user I want to see which muscles I've worked this week, on the body map, so I can spot what I'm missing.
- **PRG-7** As a user I want to be told when I've done more rounds than ever in a workout with a time limit, so I know I'm getting fitter.
- **PRG-8** As a user I want a bar per muscle group for this week's sets, so I can see which I'm underworking.
- **PRG-9** As a user I want the history to suggest which of my workouts to do next, one that works the muscles I've used least this week.
- **PRG-10** As a user I want the workout summary to tell me which exercises to step up next time, with more weight, more reps or a longer time, when I got every set's reps or ran every set's time, and to put it on the workout with one tap.
- **PRG-11** As a user I want the workout summary to show which muscles the workout worked, on the body map.
- **PRG-12** As a user I want a chart of the time I've spent working out each week, so I can see whether I'm keeping it up.
- **PRG-13** As a user I want to see how many reps (or how long) I've done of each exercise in the last 7 days, and which set a personal best, so I can see what my week's training added up to.
- **PRG-14** As a user with one kettlebell, I want a kettlebell workout to use the same weight throughout and to step me up in reps rather than weight, and to be told, with a well done, when I'm ready for a heavier kettlebell.
- **PRG-15** As a user doing a kettlebell ladder, which keeps its shape, I want to be told to rest a little less next time when I've done it in full, so it still moves on.
- **PRG-16** As a user who's just finished a workout, I want a few stretches suggested for the muscles it worked hardest, made for that workout, so I can cool down without working out which.

## Rules

### Sessions

- A **session** of an exercise is one workout in the history with sets of it: its sets linked to the exercise, from every step that was it. Sets with no exercise (an unnamed rep step) aren't anyone's.
- Bests count **across all workouts** the exercise is in, not per workout (EXR-1), and only from logged sets, so a stopped workout counts for the sets that were done.

### What it's measured by

- **Weight**, where any set of it had a weight; otherwise **reps**, where it has any rep sets; otherwise (timed sets only) **time**. It's worked out from the sets logged, not from the exercise's "Reps" or "Timed".

### Personal bests (PRG-4, PRG-2)

- **Heaviest**: the heaviest weight lifted for at least 1 rep, with the most reps done at it, e.g. "100 kg × 5".
- **Estimated one-rep max**, by the Epley formula: weight × (1 + reps ÷ 30), to the nearest 0.5 in the unit shown; a single rep is the weight itself. Shown with the set it came from, e.g. "116.5 kg, from 100 kg × 5". It isn't capped at the weight wheel's top.
- **Most reps** in one set, with its weight if it had one, e.g. "12 @ 60 kg", or "25" for bodyweight. Of equal reps, the heavier set.
- **Longest**: the longest timed set, e.g. "1:30". Timed sets are only logged from October 2026 (see [history](history.md)).
- Each shows only when a set counts towards it, so a bodyweight exercise has most reps only, and a timed one the longest only.
- On a tie, the **first time** it was done stands, dated then.

### On the exercises list (PRG-3)

- A card of an exercise with sessions adds **Latest**: its latest session's sets as the history writes them, and the date, e.g. "Latest 3 × 10 @ 60 kg · 18 Oct" (the year is added if it wasn't this year). A session with two steps of it joins them with " + ".
- And **Best**, by what it's measured by: the heaviest weight ("80 kg"), the most reps ("25 reps") or the longest ("1:30").
- Cards of exercises not done yet are unchanged.

### On the exercise page (PRG-4)

At the end of the page, after How to do it and Tips (since 2026-11-17; it was under the body map), a **Progress** section:

- With no sessions: "Nothing logged yet. Do it in a workout and its bests and progress show up here."
- **Bests**, as tiles, each with when it was set.
- **A chart**, titled by what it shows: "Estimated one-rep max" (by weight), "Most reps in a set" (by reps) or "Longest set" (by time). One point per session: the session's best of that. A session with no set that counts (e.g. a bodyweight session of a weighted exercise) has no point.
    - **Range**: 4 weeks, 3 months, Year (365 days), or All (the default). A fixed range runs to today; All runs from the first session to the latest. With nothing in range: "Not done in the last 4 weeks." (and so on).
    - The value axis runs between round numbers (whole reps, halves of a kg or lb, round seconds) and never below 0. Dates at each end of the time axis.
    - **Reading it**: hovering snaps to the nearest workout and shows its value, date and workout. With the keyboard, the chart takes focus, starts on the latest workout, and the left and right arrows (and Home and End) step through them; screen readers hear each, e.g. "105 kg, 21 October 2026, Legs".
    - **Show as a table**, at the right of the chart's title, over the range buttons, puts a table **in place of the chart** (since 2026-11-08; until then it was under the chart and added the table below it) of the same points in range: date, workout and value. The button, now **Show as a chart**, swaps the chart back. Being by the title, it doesn't move as they swap, so focus stays on it.
- **Recent sessions**, newest first: the 5 latest, then "Show all N". Each has its date and workout, linking to it in the history (`/history?run=<id>`), and its sets as the history writes them.
- Weights are in the unit chosen in You → Profile.

### Mid-workout: last time (PRG-1)

- On a rep step linked to an exercise, under its reps and weight: the rep sets of that exercise from the most recent workout that had any, in the history's set format, e.g. "Last time: 10, 10, 8 @ 60 kg". A workout with two steps of it joins them with " + ".
- On a step whose sets vary (BLD-11), just **the same set last time**, e.g. "Last time: 10 reps @ 45 kg" on set 2 (both sides, for a step done each side). Nothing for a set last time didn't have.
- Not the workout being done: it's in the history too once it's been ended (and taken back up) or the page closed, but its sets aren't "last time".
- Timed sets don't count, and nothing is shown the first time, or on an unnamed rep step.

### On the workout summary: personal bests (PRG-2)

- Under the sets, **Personal bests** lists each best above that this workout set, e.g. "Heaviest: 100 kg × 5" and "Most reps: 12 @ 60 kg", across every exercise in it.
- Only a **new** best counts: equalling one doesn't (the first time stands), and nor does doing an exercise for the first time, when everything would be a best.
- Nothing shows when it set none, or when it wasn't logged (ended before its first step was done).

### Most rounds in a time limit (PRG-7)

- A workout with a time limit (BLD-8) is scored by how far it got: full rounds, then steps done of the next, e.g. "7 rounds + 3" beats "7 rounds + 1" and "6 rounds + 5".
- On the summary, under **Personal bests**: "Most rounds: 7 rounds + 3", when it got further than every other run of the **same workout to the same time limit** that ran out. Runs stopped before time was up don't count, nor do other time limits (20:00 isn't compared with 10:00).
- As with the other bests, a tie isn't one, and nor is the first run.

### In the history

- **"This week" means the last 7 days** on Progress and Today (since 2026-11-14): the 7 × 24 hours up to now, as "Last 7 days" counts them, so it's never shorter on a Monday. The muscles (PRG-6, PRG-8), the suggested workout (PRG-9) and the exercises this week (PRG-13) all count it. Only the plan's week (see [planning](planning.md)) and the time per week's bars are Monday to Sunday, and the bars are named by their days, not "This week", so the two never disagree on the page.
- Each set line's name links to its exercise's page, where it's linked to an exercise that's still there (see [history](history.md)).
- **Time per week (PRG-12, since 2026-11-06):** a card under "Last 7 days", titled "Time per week", with a bar for each of the **last 12 weeks**, Monday to Sunday on the device's calendar as the plan's weeks are (see [planning](planning.md)), oldest at the left and this week at the right, however far into it. Someone newer sees only the weeks **from the week of their first workout** (since 2026-11-08; until then a new user saw 12 weeks, nearly all empty): those weeks share the width, their bars wider (up to about twice a 12-week bar). Each bar is the time spent in the workouts started that week, as the history counts it (pauses don't count). A week with no time has no bar. The time axis starts at 0 and runs in round steps to at or over the longest week: in minutes ("30m") under an hour, then hours ("1h", "1.5h"). Under the bars, the first week's Monday ("17 Aug") under the first bar and the latest week's ("9 Nov") at the right; with only one week, just its Monday. Until 2026-11-14 the right said "This week", which disagreed with the last 7 days above it.
    - Over the bars, the **chosen week**: its time, big, e.g. "1:26:30", then the week's days and its workouts: "9–15 Nov · 2 workouts", or "28 Sep – 4 Oct" across two months (until 2026-11-14 the latest two were "This week" and "Last week"). It starts on the latest week, and its bar is lit in the time's colour, the others quieter (at 3:1 or more on the card all the same).
    - A **tap** (or a click, or a finger dragged across) chooses the week under it, and it stays chosen, lit and in the readout, until another is chosen (since 2026-11-15; until then it went back to this week as the finger lifted). A mouse or pen hovering shows the week under it, going back to the chosen one as it leaves. With focus on the chart, the **left and right arrow keys** step through the weeks from this week, and **Home** and **End** go to the first and this week. A screen reader hears each as it's chosen: "Week of 19 October: 1 hour, 1 workout", or "Week of 26 October: no time, 0 workouts"; the chart's description says "The last 12 weeks", or "The week of 9 November" with only one. A week chosen with the keys stays chosen as focus leaves, as a tapped one does.
    - **Show as a table**, at the right of the card's title, puts a table **in place of the bars** (since 2026-11-08; until then it was under the chart and added the table below it): a row a week shown, oldest first, with the week's Monday, its workouts and its time. The chosen week stays over it. The button, now **Show as a chart**, swaps the bars back. Being by the title, it doesn't move as they swap, so focus stays on it.
    - With nothing in the last 12 weeks: "No workouts in the last 12 weeks." It's on the page only with something in the history, as all but the empty message is.
- **Muscles worked this week (PRG-6):** under "Last 7 days" (and on Today, the map without the bars, since 2026-11-06: see [home-and-navigation](home-and-navigation.md)), the [exercises](exercises.md) body map, shaded by the sets of workouts started in the last 7 days: each set counts 1 for its exercise's main muscles and ½ for supporting ones, and each side of an exercise done each side half that, so a left and a right make one set. A muscle with 1 or more shades as main, under 1 as supporting, and the map's lists say which. Sets with no exercise, or of an exercise since deleted, don't count, nor (since 2026-11-12) stretches, which ease a muscle rather than train it. Not shown with no sets to count.
- **Bars per muscle (PRG-8):** under the body map, a bar for each of the 16 muscle groups, most worked first and A to Z on a tie, with its sets this week counted as above. Each track has its muscle's **aim**, the sets a week to reach, as a **line across it**, set by **Sets a week per muscle** in You → Profile (see [settings](settings.md), since 2026-11-19), 2 to 30, which **Training for** sets to start with: for **Muscle** (the default), **at least 10 sets a week**, the usual advice for building muscle; for **Fitness**, about two thirds of that, **6**. The **small muscles** that are rarely trained on their own (abductors, adductors, forearms, obliques) aim for about two fifths of it, rounded and never under 1: **4** of 10, **2** of 6, 6 of 14. There's **no most** (since 2026-11-19; until then the aim was a band, 10 to 20 sets for Muscle, and a bar past it turned pink as **over**, which Dan found too easy to reach): a bar far past its aim looks like any other that reached it. The line is **drawn over the bar**, so the aim still shows once a bar has passed it: a line just past the aim, on the track while the bar is short of it or ends on it, and a notch cut in the bar (in the track's colour) once the bar is past it. The line stands out from the track, and the notch from every bar's colour, at 3:1 or more. Short of the aim is **under** (a grey bar), at it or past it **reached** (cyan); the bar ending short of the line or past it says the same without colour, and a screen reader hears e.g. "Glutes: 2 sets, under 10" or "Chest: 22 sets, 10 reached". The tracks run to twice the highest aim (20 sets at 10), or further when a muscle has had more. A key under them says the line is the sets a week to aim for, set in You → Profile, fewer for small muscles, and explains the counting.
- **Exercises this week (PRG-13, since 2026-11-14):** under the muscles, a card titled "Exercises this week": each exercise with a set in the last 7 days, its name linking to its page (PRG-4), whose **‹ Progress** comes back to this row, in view and focused, and at its right what was done: "28 reps · 3 sets", the time held for a timed one ("1:45 · 2 sets"), or both for one done both ways ("40 reps · 1:30 · 5 sets"). Screen readers hear "28 reps in 3 sets", "1 minute 45 seconds in 2 sets".
    - **Each side** (BLD-10): each side's sets are counted apart, and the side that did more stands for both, so a left and a right make one set: "20 reps each side · 2 sets" for 2 × 10 each side, and the same for one ended before its last right.
    - **Volume** (since 2026-11-14): where any set had a weight, the total of weight × reps over those sets, in the unit chosen in You → Profile, to the whole kg or lb: "28 reps · 3 sets · 1,680 kg lifted", heard as "28 reps in 3 sets, 1,680 kg lifted". Sets with no weight add nothing, so a bodyweight exercise has none. For one done each side it's both sides together, the total lifted, though its reps are each side's.
    - **New bests:** under the line, each personal best it set this week, with a **New best** tag: "Heaviest 62.5 kg × 10", "Most reps 12 @ 60 kg" or "Longest 1:30", worded as on the exercise page, in the unit chosen in You → Profile. Screen readers hear "New best, heaviest: 62.5 kg for 10 reps". They count as the workout summary's do (PRG-2): only one that beat an earlier session, so not one from the first time it was ever done, nor an equal, as the first time stands; one beating a session earlier in the same week counts. The estimated one-rep max isn't listed, being a guess rather than something done.
    - **Order:** those with a new best first, then most sets, then A to Z. The first **6** show, then **Show all 14** (or **Show fewer**), as the exercise page's recent sessions do; focus stays on the button.
    - Sets with no exercise, or of an exercise since deleted, aren't listed; stretches are, as time held. With nothing in the last 7 days there's no card.
- **Suggested next workout (PRG-9):** a card on Today, under the week and Due today, with nothing planned this week, or on a day of a planned week with nothing planned (then offered as "Fancy a workout today?" and steering clear of the next workout planned: see [planning](planning.md), since 2026-11-06), with the saved workout whose muscles are furthest short of their aims this week (the bars' aims, PRG-8, so lower for small muscles, and following Sets a week per muscle): each muscle's sets this week over its aim, averaged over the muscles its exercises work, its main muscles counting twice its supporting ones, lowest wins. So 5 forearm sets (aim 4) count as more worked than 8 chest sets (aim 10). On a tie, the one done longest ago (never done first), then their order on Workouts. It names up to three of its main muscles, furthest short of their aims first, in words rather than their sets and aims, which were hard to read on a card: "It works your Chest, which you haven't trained in the last 7 days." when none of them has had a set in the last 7 days, otherwise "It works your Quads and Glutes, which you've trained least in the last 7 days." (since 2026-11-08; until then "For Chest (0 of 10 sets), the least worked this week."). Under it, **See your week ›** goes to Progress, whose bars show each muscle's sets against its aim. **Start**, the filled main button, starts it, as a workout's Start on Workouts does. It was on the Progress (then History) page too, under the muscles, until 2026-11-03; it's on Today alone now, where you go to see what to do. Workouts with no step linked to an exercise aren't suggested, nor (since 2026-11-12) those of only stretches, such as the mobility workouts, as they train nothing; and a mobility day is never the next workout to leave muscles fresh for; only workouts you can do with the equipment you've said you have are suggested (since 2026-11-18; with none picked yet, any), so No equipment never gets a dumbbell or barbell workout; with none to suggest, there's no card. Shown even in a week with no sets, when it's the workout done longest ago.

### On the workout summary: next time, muscles and the next workout (PRG-9–PRG-11)

- **Next time (PRG-10):** under the sets, for each rep step of this workout where **every set got the step's reps**: with a weight, one step up, by the same rule as PRG-5 (the heaviest sets only, 2.5 kg or 5 lb), e.g. "Bench press: try 82.5 kg, up from 80 kg"; with no weight, **one more rep**, e.g. "Push-ups: try 13 reps, up from 12". A step that fell short, or is at the top of its wheel (300 kg, 100 reps), has none, and with none there's no section. The same exercise in two steps stepping up alike is said once. It follows the sets as they're corrected (RUN-7), and goes by the step's reps as it was when the workout ended. Each has **Apply** on its right, which puts the step-up on that step of the saved workout (and of this run, so Back to workout carries on with it, as turning the face's wheel would). The line stays, with "Applied" in place of the button and focus moved there, even though this run's sets no longer reach the new reps. A line said once for two steps applies to both. A workout no longer in the library has no Apply; a ready-made one has (since 2026-11-08), as it keeps your reps and weights (see [library](library.md)). Left unapplied, nothing on the saved workout changes, and the weight one comes up again mid-workout next time as "Try 82.5 kg" (PRG-5). Answering **Yes, use next time** to "Use these settings next time?" after applying puts the steps back to this run's last sets, as it always does. On a step whose sets vary (BLD-11), each set is judged against its own reps, and the step up is the same for every set, so the shape stays: "Leg press: try 2.5 kg more on each set" (or "try 1 more rep on each set" with no weight), and Apply adds it to every set. A **timed exercise** (since 2026-11-15) where **every set ran its whole time** (both sides; none skipped part-way, RUN-12) is 5 seconds longer, e.g. "Plank: try 35 seconds, up from 30 seconds", or "Plank: try 5 seconds more on each set" where its sets vary; none past the longest a step can be (99:59). Its Apply puts it on the saved workout only, not this run, whose clock it would move. The hint above them reads "Every set was done in full, so step up:".
- **Muscles worked (PRG-11):** the [exercises](exercises.md) body map, shaded by this workout's sets: main where any set's exercise has the muscle as main, supporting where it only ever helps, with the map's lists saying which. Sets with no exercise, or of one since deleted, don't count; with none that do, there's no section.
- **Suggested next workout (PRG-9):** the same card as on Today, counting this week's sets with this workout's in, under the note. There's no Start on the summary: it's started from Today or Workouts.

### On the workout summary: stretch what you worked (PRG-16, since 2026-11-18)

- **A stretch for every muscle group:** the built-in stretches held for a time (see [exercises](exercises.md)) have at least one whose main muscles include each of the 16 groups, batch 12 adding the chest, shoulders, biceps, triceps, forearms, obliques, traps, abductors and adductors. Each is marked as done **standing** or **on the floor**, and **each side** or not.
- **Made for the workout:** each set counts a point for each muscle its exercise mainly works, and a quarter for each it supports; stretches, unnamed sets and sets of an exercise since deleted count nothing. The muscles with at least a point (so mainly worked by some set, not only supported) are taken most first, ties in the app's order. For each, unless a stretch already picked mainly stretches it, the stretch for it that also eases most of the rest the workout worked (its main muscles' points, and a quarter of its supporting ones'), the first listed on a tie. At most **5 stretches**, so it's a few minutes, not another workout: a workout of many muscles leaves out the ones it worked least.
- **The order:** standing ones first, then on the floor, so you get down once, most worked first within each, under **Standing** and **On the floor** where it has both. Each is held **30 seconds**, each side for one done each side (with the Switch sides countdown between, from Settings), with no rests, running straight on (BLD-18).
- **The card:** under Muscles worked, **Stretch what you worked**, "About 4 min for your Chest, Triceps and Shoulders, each held 30 seconds.", the stretches as a workout's outline, and **Start stretches** ("Start stretches, about 4 minutes" to screen readers). Not on the summary of a workout of only stretches (active rest, including these stretches themselves), nor of one with no set that mainly works a muscle.
- **Start stretches** ends this run, kept in the history as it is (its note saved), and starts the stretches on the workout page at once, focus on Pause. They're logged as **Cool-down stretch**, as any run is, but aren't a saved workout: nothing is added to Workouts, a reload carries on with them from the run's own copy, and their summary has no Apply (a workout no longer in the library). Their sets don't count on Progress, as stretches never do.
- **Ready-made too:** for a stretch planned rather than suggested, Workouts has **Upper-body stretch** and **Lower-body stretch** (see [library](library.md)).

### Kettlebell workouts (PRG-14)

- A **kettlebell workout** is one where an exercise needs a kettlebell outright (a swing, a halo) and every other can be done with only a kettlebell, or needs nothing (a goblet squat, a chainsaw row, a glute bridge). Its **kettlebell steps** are its rep steps whose exercise uses a kettlebell. It's taken that you have **one kettlebell**. A workout with a barbell, or dumbbells only (e.g. a curl) beside a swing, isn't one, and goes by PRG-5 and PRG-10 as ever.
- **One weight:** setting the weight on a kettlebell step mid-workout puts it on every other kettlebell step that has **no weight or the old weight**, here and in the saved workout (or a ready-made one's kept reps and weights). So the weight is said once, the first time, and once more on getting a heavier one. A set given another weight on purpose keeps it. Removing the weight isn't shared.
- **In Create** (since 2026-11-17): the same, as a workout's built. A weight turned to on one kettlebell step goes on the others at the old weight or none; a kettlebell exercise added starts at the workout's one weight, or My kettlebell with none yet; and saving a kettlebell workout at one weight makes it My kettlebell, so starting it doesn't move it back. Only exercises picked count, as a typed name is linked to its exercise when it's saved. See [build-a-workout](build-a-workout.md).
- **My kettlebell** (since 2026-11-17): that weight is also **your kettlebell's**, kept with your profile (so it syncs), and on You → Profile as **My kettlebell** for someone with a kettlebell (see [settings](settings.md)), where it can be changed too. **Starting** a kettlebell workout moves its kettlebell steps to it, here and in the saved workout, where they're at one weight or none; one with two weights in it, put there on purpose, starts as it is. So a heavier kettlebell set in one workout starts every other at it.
- **Reps, not weight:** a kettlebell step where every set got its reps goes up **one rep** in Next time (PRG-10), weight or none, e.g. "Swing: try 16 reps, up from 15". Up to **20 reps**, and no further. A kettlebell step whose **sets vary** (BLD-11), such as the Kettlebell swing ladder's 10, 15, 20, 25, 20, 15, 10, has **no more reps and no heavier kettlebell**, but a shorter rest instead (PRG-15, below): its shape is the workout, a rep more on each set would spoil it, and a set of 20 in it doesn't show the kettlebell's too light. Its sets still count in the log and towards bests. Mid-workout, there's no "Try 18.5 kg" (PRG-5) on a kettlebell step.
- **A heavier kettlebell:** at the end of a workout where a kettlebell step at **20 reps or more** (with its sets alike) got every rep, the summary has a card above Sets, **Time for a new kettlebell**: "Congratulations, you're ready to go up in weight. Every set got its reps, at 20 or more:", the steps' sets (e.g. "Kettlebell swing: 20 reps @ 16 kg"), and "With the heavier one, drop back to fewer reps and build up to 20 again." It follows the sets as they're corrected, and shows again each time it's earned. Next time has nothing for those steps.

### A shorter rest for a kettlebell ladder (PRG-15)

- A **kettlebell step whose sets vary** (the Kettlebell swing ladder's 10, 15, 20, 25, 20, 15, 10, or a pyramid of your own with one kettlebell), alone in its group with a rest after each set, where **every set got its reps**, has in Next time **5 seconds less rest**: "Kettlebell swing: try resting 40 seconds between sets, down from 45 seconds". Never below **15 seconds**. It's the same swings in less time, which is how a ladder moves on, as it gets no more reps and no heavier kettlebell. A step in a superset has none, as its rest is shared.
- **Apply** puts it on the saved workout for next time, not this run, whose clock it would move (as a longer time does). On a ready-made workout such as the swing ladder, it's kept with your reps and weights, with no copy, and Reset reps and weights puts it back.

### Mid-workout: suggested next weight (PRG-5)

- By **double progression**, from the same sets as "Last time" (PRG-1): where every set at last time's **heaviest** weight got at least the step's reps, try one step up: **2.5 kg**, or **5 lb**. Lighter sets, e.g. warm-ups, don't count. Otherwise, stay at the same weight.
- A step up shows under "Last time" as a button, e.g. "↑ Try 62.5 kg". Pressing it puts that weight on the step's weight wheel, as turning the wheel would (RUN-6): for this set, the rest of the workout and next time. It's a suggestion only; the wheel can still be turned to anything.
- It shows only while the step is still at last time's weight. Once the weight's been changed (by the button, the wheel, or in setup), it's the user's call, and the button goes.
- Staying at the same weight needs nothing doing, since the wheel already has it, so nothing shows. Nor does anything when last time had no weight, or was at the wheel's top.
- **On a step whose sets vary** (BLD-11), each set of last time is judged against **its own reps**, set by set (both sides), not just the heaviest. Where every set got its reps, and each set with a weight was done at it, the whole step moves up one step: it shows **once, on set 1**, as "↑ Try 2.5 kg more on each set", and pressing it adds that to every set with a weight, here and in the saved workout, so the pyramid keeps its shape. Where any set fell short, or a weight's been changed since, nothing's suggested. There's no suggestion per set, which would change the shape the user built; it agrees with Next time on the summary.

## Platform notes

- **Web:** the sums are in `src/app/models/progress.ts` (`sessionsByExercise`, `progressMeasure`, `exerciseBests`, `sessionValue`) and the wording in `src/app/exercises/progress-format.ts`. The page's section is `ExerciseProgressComponent` (`src/app/exercises/exercise-page/exercise-progress/`), an inline SVG chart in the `--accent` colour. `/exercises` now waits for the history to load, as `/exercises/:id` and `/history` do. Last time is `WorkoutFaceSlideComponent.lastTime` (with `describeSets()` from `src/app/history/history-format.ts`), the summary's bests `WorkoutSummaryComponent.personalBests` (most rounds with `isMostRounds()` in `models/progress.ts`), and the muscles this week `MusclesThisWeekComponent` (`src/app/history/muscles-this-week/`, on the Progress page and Today), shown with `BodyMapComponent`, whose code (with its drawings) it loads only once there's something to show, keeping its space till then, and `MuscleBarsComponent` (`src/app/history/muscle-bars/`). The counting, the aims (`DEFAULT_WEEKLY_SETS`, `SMALL_MUSCLES`, `weeklyAim()`, `smallAim()`, `readWeeklySets()`, with the sets a week as `SettingsStore.weeklySets`, set by `WeeklySetsFieldComponent` in `shared/components/weekly-sets-field/` on Profile and in the setup) and the suggestion (`suggestNextWorkout()`, by `shareOfAim()`) are in `src/app/models/muscle-balance.ts`; the bars' colours are the `--balance-*` tokens, the aim's line a `.bars__aim` span after the fill (`--balance-aim` on the track, `--muscle-idle` where covered). The suggested weight is `suggestedWeight()` in `models/progress.ts` (`canStepUpEachSet()` and `steppedUp()` for a step whose sets vary, shown by `WorkoutFaceSlideComponent.eachSetStepUp`) (the step up is `WEIGHT_INCREASE` in `models/weight.ts`), shown by `WorkoutFaceSlideComponent.nextWeight`. On the summary, Next time is `progressionSuggestions()` in `models/progress.ts` (`SummaryStepUpsComponent`, in `src/app/workout/workout-summary/summary-step-ups/`), the muscles `musclesInSets()` in `models/workout-muscles.ts`, and the next workout card `SuggestedWorkoutComponent` (`src/app/history/suggested-workout/`), shared with Today. The time per week is `timePerWeek()` in `models/time-per-week.ts` (weeks from `startOfWeek()` in `models/plan.ts`, stepped by the calendar so a clock change can't move a week's start off midnight), drawn by `TimePerWeekComponent` (`src/app/history/time-per-week/`). The last 7 days are `inLastSevenDays()` and `lastSevenDaysFrom()` in `models/history.ts`. The exercises this week are `exerciseWeeks()` in `models/progress.ts`, with the new bests from `newBests()` (which the summary's bests use too), worded by `describeWeek()` in `exercises/progress-format.ts` and shown by `ExercisesThisWeekComponent` (`src/app/history/exercises-this-week/`). Both charts share their axis, grid and table styles (`src/styles/_chart.scss`) and their arrow keys (`chartKeyMove()`, `shared/chart-keys.ts`).
