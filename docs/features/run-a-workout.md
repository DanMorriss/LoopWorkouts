# Run a workout

## Stories

- **RUN-1** As a user I want to see at a glance which step I'm on, how long is left and which round it is, from across the room.
- **RUN-2** As a user I want to see what's coming next, so I can get ready for it.
- **RUN-3** As a user I want the workout to wait while I do a set of reps, and carry on when I tap Done.
- **RUN-4** As a user I want to know when I've finished, and be able to note how it went.
- **RUN-5** As a user I want the countdown to stay right even if my phone sleeps or I switch apps.
- **RUN-6** As a user I want to change the reps or weight while I'm on a rep step (e.g. going up a weight, or managing fewer reps), so what I log is what I did, and next time starts from there.
- **RUN-7** As a user I want a summary of how a workout went when I finish or end it, where I can correct a set, add a note, and go back to the workout if I ended it early.
- **RUN-8** As a user I want a workout with a time limit to count my rounds up, show the time left, warn me as it runs out, and stop when time's up, so I can just keep going until then.
- **RUN-9** As a user I want to check how a step's exercise is done, mid-workout, without leaving it.
- **RUN-10** As a user I want the workout to show which set, side or round I'm on, and the section I'm in, so I know where I am in a long gym workout.
- **RUN-11** As a user I want to swap an exercise for something equivalent mid-workout, e.g. when someone's on the machine, so I can still work those muscles.
- **RUN-12** As a user I want to skip any step, e.g. a warm-up I've done already, a rest I'm ready to cut short or a set I'm leaving out, and carry on from the next step without it logged as done.
- **RUN-13** As a new user I want a short tour of the workout page before my first workout's clock starts, so I know what's on it without working it out mid-exercise.
- **RUN-14** As a user I want a timed exercise after a long rest to wait until I press Start, so I can get set up (a plank's position, a carry's weights) without losing any of its time.
- **RUN-15** As a user I want a change I save to the workout I'm doing to apply to it straight away, e.g. another exercise for one later on, rather than only next time.
- **RUN-16** As a user I want an exercise I skip because I can't do it right now (the machine's taken, say) kept for later, so I can pick it to do next once I can, without losing it from the workout.

## Rules

### Timing

- Each step counts down from its full time, in whole seconds, then the next starts at once. Rounds follow straight on.
- Rest after the last work or rep step of the **last round is skipped** (see [build-a-workout](build-a-workout.md)), so the workout finishes there.
- A step with **sets** runs them one after another, with its rest after each, the last included, then the next step starts (BLD-9). The last set's rest is skipped when it would end the workout (the whole workout's last round), and when a rest step comes next, which takes its place.
- A step done **each side** (BLD-10) runs both sides in each set, then the rest after the set: the side the settings start with first. A rep step's second side waits for Done like any rep step, with nothing between. A timed step's sides have **Switch sides** between them, a countdown in the rest colour (5 seconds to begin with, or as set; none when it's Off), which isn't a set and isn't logged.
- How sides run is taken from the settings **when the workout starts** and kept with it (refreshing the page too), so changing them mid-workout can't move its clock; the next workout uses the new ones.
- A workout that runs **until stopped never finishes** on its own.
- The countdown is worked out **from the clock** (now minus when it started, less any pauses), never by counting ticks. If the app is held up, it shows the right time as soon as it can, rather than running slow. The clock ticks on each quarter second of the run, and on each alarm, so the face rolls on to a step and the phone vibrates in the same tick the step's beep was booked for.
- Whole workout length = rounds × (sum of timed steps in a round) − (rest at the end of a round). Rep steps add whatever time they take on top.

### A time limit (RUN-8)

- Rounds go on one after another, **as many as fit**. Time's up when the countdown plus the time spent on rep steps, less any time skipped, reaches the limit: **reps and rests count**, pauses don't, and the time a skip saves goes to **more rounds** (RUN-12).
- When time's up part-way through a **timed exercise**, it **runs on to its end**, so the last one can be finished (since 2026-11-16): the time left reads "**Time's up · finish this one**", in the accent colour, and the workout finishes as the step ends. Skip finishes it there and then, logging the time it ran.
- Otherwise, in a rest, Switch sides or a rep step, or just as a step was due to start, the workout **finishes at once**, as if it ran to its end. Either way: "Time's up" on the summary, the finish alarm, and logged as finished.
- **Time's up in a rep step** asks how many reps were done of it **before the summary** (since 2026-11-17; on the summary until then): a card over the workout, "**How many reps?**", "Time ran out during Push-ups.", with a Reps wheel (starting at the step's reps), **Add set** (where focus starts) and **Skip**. Add set logs that many reps at the step's weight; Skip, ‹ Back, Escape or a tap outside leave it out. Either way the summary follows, with focus on its heading. The set is like any other after that, and can be changed with the rest, but it doesn't make the score "+ 1", as the step wasn't finished, and "Use these settings next time?" leaves it out. Skipped, it isn't asked again, even after a reload (since 2026-11-18).
- **The score** is the full rounds done, and the steps done of the round it ran out in, rests left out: "7 rounds + 3". A timed exercise run on to its end counts, and is logged as a timed set; a rep step time ran out in isn't done (see the summary, below).
- **Time spent** is the time limit, plus the time a last timed exercise ran on past it.
- **Alarms**: the steps' alarms as usual, up to the end; a short tick (see [alarms](alarms.md)) at 10 seconds left, and at 3, 2 and 1; then the finish, as the last timed exercise ends if it runs on (with its own countdown beeps after time's up, when those are on). The end is known even while a rep step is waited on, so it's booked then too.

### Rep steps

- When the clock reaches a rep step, the workout **stops and waits**, however long it takes. The ring is full and still, in violet, and the face shows the reps, e.g. "20 reps", with the weight under them, e.g. "60 kg", or a quiet "+ kg" with none (see RUN-6).
- **Done** is the **Up next** card under the ring (below): on a rep step it reads "**DONE · UP NEXT**", e.g. "Rest", "01:00", with → at its end in the next step's colour. Screen readers hear "Done. Next: Rest · 01:00". When what's next is an exercise, its **name** is a button of its own (since 2026-11-18), dotted under with an **(i)** beside it, as names on the face are, opening that exercise's details with Swap exercise, as the card does on other steps. So one about to start its clock, e.g. a plank, can be read about first, without pausing or tapping its name once it's running. The rest of the card is still Done. The rep step carries on underneath; closing the details puts focus back on the name. Screen readers hear Done, then a button named "Plank" that opens a dialog. Before a rest, or a step that's only a name, the whole card is Done. It moves on to the next step, which starts from its **full time**. The big button stays **Pause**, as on any other step. While paused, the card is only what's next again, with an (i) for the next exercise when it is one.
- If Done had focus and the next step isn't a rep step (so Done goes), focus moves to Pause.
- As a rep step comes round, **Done swells once**, as it's the user's move now (not with reduced motion). The phone vibrates with the step's alarm, as for any step.
- **Pressing Done** finishes the set: the full ring stays a moment over the next step's, swelling out as it fades (not with reduced motion), in the same frame as the next step's beep and vibration.
- The time spent on reps doesn't come off any countdown, but it **counts as time spent** in the history.

### Skipping a step (RUN-12)

- **Skip** (⏭, captioned "Skip") is beside Pause, to its right, on **every kind of step**, like a media player's: for a warm-up you've done already, say, a rest you're ready to cut short, or a set you're leaving out. It moves on to the next step, which starts from its **full time**, as Done does on a rep step. Not while paused, when the controls under the ring go.
- Screen readers hear "Skip step", or "Skip rest" on a rest.
- The next step's alarm sounds and the phone vibrates at once, as the step starts; the skipped step's countdown beeps don't.
- A skipped **rep step** isn't logged: it's Done without its set, so its ring doesn't fill, and the time spent on it still counts, as on any rep step. A skipped **timed exercise** is logged with the time it actually ran, in whole seconds (none if under a second), not its full length. A skipped **rest** isn't logged, as rests never are.
- What's skipped doesn't count as time spent in the history. With a **time limit**, it doesn't count towards the limit either, so the time saved goes to more rounds. Skipping the last step of the last round ends the workout; skipping an exercise there puts it aside, so it asks first whether to do it before finishing (RUN-16).

### Doing a skipped exercise later (RUN-16)

- Since 2026-11-18, an **exercise skipped** (a timed or rep step with a name, not a rest or Switch sides) is **put aside** for later, as well as skipped as before (RUN-12). A small **dumbbell button** shows at the **top right** of the workout page while there's one, with a red **count** on its corner when there's more than one. So it's clear why it's there, **a copy of it flies up out of the ring** into the corner as the exercise is skipped (since 2026-11-19), on a spring, and the button gives a small bump as it lands; the count pops as it lands too, rather than changing as Skip's pressed. With reduced motion, the button fades in instead. Nothing else changes: ignored, it's simply skipped. Not in a workout with a **time limit**, where a skip's time goes to more rounds instead.
- **With one**, pressing it opens a small menu under it, "**Do Plank next?**", with its amount ("00:30", or "Set 2 of 3 · 10 reps @ 60 kg", with the round where there's more than one) and **Not now** and **Do it next**. **With more**, it lists them, "**Skipped · do one next**", in the order they were skipped (or put in at the end, see below), each its name and amount, and pressing one picks it. Escape, Not now or a tap elsewhere closes it, with focus back on the button. Screen readers hear the button as "Skipped: Plank" or "2 skipped exercises".
- **Picked**, it's **up next**, and goes there the way it came (since 2026-11-19): a copy of the button **flies down to the Up next card's icon**, shrinking as it lands, and the card's words come in as it does, with a small bump; with reduced motion, they just fade in. It runs **straight after the step that's on now** (after the rest, during a rest; after Done, on a rep step), from its full time, then the workout carries on with what would have come next. The Up next card says so, and the bar says "**Plank is up next**" with **Undo**, which goes as soon as **anything else is pressed** (since 2026-11-19), e.g. Skip or the Up next card, so it doesn't stay in the way, or once the exercise starts. Focus goes back to the button, or, when that was the last one, to Done or Pause. Several picked run one after another, the latest first; picked during a step done later, it's after that one.
- While it runs, the face shows it as usual, with "**Skipped earlier**" in the section line (and to screen readers), and the round line stays where the workout is. Its **set is logged where it was skipped**, as if done then: a rep step's with Done, a timed one's for its full time (or the longer of the two times it ran, skipped again part-way). Skipped again, it goes back on the list. Its (i) opens its details without Swap exercise, as a swap is from where a step is in the run.
- The workout's clock **holds** while it runs, as at a rep step: its time counts as time spent, its alarm and countdown beeps sound as any step's, and everything after it moves on by its time. Picked during the last step, the workout finishes once it's done. A reload carries on with the list, what's picked and what's on.
- **At the end**, with any still on the list (since 2026-11-20), the workout **asks before it finishes**, in a dialog over the page: "**Do Plank before you finish?**", with "You skipped it earlier" and its amount, **Do it now** and **Finish**. With more, "**Do them before you finish?**", listing them as the menu does, with **Do them all** and Finish. Until it's answered, the workout isn't logged and the summary doesn't open; a reload asks again. Focus starts on Do it now, or Do them all.
- **In the list**, each one can be pressed to do it on its own, **dragged by its handle** (⋮⋮) to another place, or moved up a place with its **↑** (off on the first), for a keyboard or a screen reader, which hears where it went ("Squats moved to 1 of 2"); focus stays on its ↑, or on the exercise once it's first. The order is the list's from then on, the menu at the top's too. On a phone, dragging a handle moves the row, not the sheet.
- **Do them all** runs them one after another, in the list's order, with focus on Pause, then the workout finishes. One skipped again on the way goes back on the list, and the rest carry on; at the end it asks again.
- **One picked** runs straight away, from its full time, with focus on Pause, then the workout finishes, or asks again about any left. Its set is logged where it was skipped, as for any done later. **Finish**, ‹ Back, Escape or a tap outside finish it with them undone. The time spent deciding isn't counted: the time spent is the workout's and those done at the end, and the finish is dated when it's pressed or the last of them ends. The finish alarm sounds as the workout reaches the end, and again after one done there.
- Ended while it asks (another workout started, or the tab closed), the run is logged as finished, without them.

### What's on screen

- **Title**: the workout's title. On a phone it takes the place of the app name in the header.
- **Section line** (RUN-10), above the round line: the heading of the part it's in, if there's one before it, and how far through the workout's exercises it is, e.g. "Knee rehabilitation · 2 of 7". Rest steps and headings don't count, and a superset counts as one; a rest step is part of the exercise before it, or the first before any. Only for a workout with headings or more than one exercise, and its room is kept for the whole run, so the ring doesn't move as it changes. One line, cut short with "…" if it's too long. Screen readers hear the count as "exercise 2 of 7", and "Knee rehabilitation, exercise 2 of 7" as each exercise starts (not on each of its sets).
- **Round line**:

    - "Round 2 of 5" for a workout of more than one round, with a dot per round (done, current, to go) when there are 15 rounds or fewer.
    - "**Last round!**" in place of the count in the final round. Never for a single-round workout, nor for the last of an exercise's sets or a superset's rounds.
    - "Round 3 of ∞" for a workout that runs until stopped.
    - "Round 3" for a time limit, with the **time left** under it, e.g. "12:34 left", in the accent colour for its last 10 seconds. Screen readers hear it with the round as each round starts, e.g. "Timed, round 3, 12:34 left"; the time left itself isn't read out as it ticks.
    - Nothing for a single-round workout.
    - **On a step with sets** (BLD-9), its sets instead: "Set 2 of 3", with a dot per set when there are 15 or fewer. The rest after a set is part of that set: resting after set 1 still says "Set 1 of 3", and the next set's line turns in as it starts. The last set says "Set 3 of 3" too. When the whole workout repeats, its round follows on the same line: "Set 2 of 3 · round 1 of 2", "· round 3 of ∞", or "· round 3" with the time left under it for a time limit. Screen readers hear "set 2 of 3", or "last set", with each set. (RUN-10; the section line is above.)
    - **In a superset** (BLD-12), its rounds the same way: "Superset round 2 of 3", or "Giant set round 2 of 3" for three exercises or more, with a dot per round, for each of its steps. Screen readers hear "superset round 2 of 3", or "superset, last round".
    - The **time left of the whole workout**, e.g. "01:20 left", beside the dots, for a set number of rounds of timed steps only. Not with rep steps, which take as long as they take, nor until stopped.
    - A **strip of the round's steps** under it, one segment per step in its kind's colour: an outline to go, filled but quieter when done, and taller with a glow for the one in progress. Only when a round has more than one work or rep step (a plain work-and-rest workout leaves it out), and no step has sets (whose round line says where it is). In a workout with sets, a superset's round (BLD-12) has one, of its steps and the rest after it; hidden from screen readers, which hear the step number, e.g. "step 2 of 5", with each step.

- **Ring**: fills as the step goes by. Timed steps fill clockwise in pink; rest fills anticlockwise in blue. Both ends of the fill are **rounded**, as a drawn line's are, where it starts at 12 o'clock and where it's got to (since 2026-11-06; flat until then, when timed steps also had a bright dot at the leading edge, which the rounded end now does the job of). The face behind the time is tinted in the phase colour, and holds still for most of the step.
- **The bubble is a glossy ball** (since 2026-11-06): the ring is shaded as a tube, lighter along its inner middle and at the top left, darker at its outer edge; and the face fills the circle inside it (it had a thin white rim until then) as a glossy ball, with a hard white highlight at its top left, a faint sheen across its top, light bounced up along its bottom rim, its curve darkening towards the edge (most at the bottom right, away from the light), a crisp edge and a shadow cast onto the ring. The middle, where the step's name and time are, stays clear. The light and shade stay still, in both themes, paused and on a rep step's full ring too, so nothing repaints as the ring fills (`.workout-ring__shine` and `.workout-ring__gloss` in `workout-ring/`, with the tokens `--bubble-light` and `--bubble-shade`).
- **Face**:
    - An **icon for the step's kind** on its own line (a stopwatch for timed, a seated figure for rest, a dumbbell for reps), so the kinds aren't told apart by colour alone.
    - The step's name under it. Unnamed work shows just the icon over the time; unnamed rest says "Rest"; unnamed reps say "Reps".
    - For a step done each side, **which side** under its name: "Left side" or "Right side". The other side rolls up from below, as a new step does. Screen readers hear it with the step, e.g. "Step-up, left side, 10 reps".
    - The name of a step that's an exercise is a **button for its details** (RUN-9; since 2026-11-15, in place of an (i) beside it), with a faint dotted line under it, as the wheels have, to say it can be tapped, and 44px to tap. It opens the exercise's details over the workout, as Create's Details does (EXR-11), but with only how it's done, as that's what's wanted mid-set (since 2026-11-15): the name, the animated demo, its description, your note, how to do it and tips. Its other names, chips, muscles and progress are left out, and **Swap exercise** is in place of Create's Pick another (RUN-11, below). The workout carries on underneath, the clock too; Space and Escape are left to the dialog while it's open. ‹ Back at its top, which stays in reach as the details scroll (or Escape, or a tap outside) closes it, with focus back on the name, or on Done or Pause if the workout has moved on to a step with no exercise meanwhile. A step that's only a name, e.g. "Jog", isn't a button. Screen readers hear it as a button named "Push-ups" that opens a dialog. While paused it's still a button, over the greyed ring, as pausing to read how it's done is what it's for (see [pause-and-stop](pause-and-stop.md)); closing the details there goes back to it.
    - A **long name** is fitted to the circle: at full size on one line if it fits; otherwise on two even lines, e.g. "Bodyweight / squat"; and only if that's still too wide, shrunk as far as it needs to be, to no less than 70% of its size. A name too long even for that, e.g. "Single-leg Romanian deadlift" on a phone, gets a third line in the same way. Past that, its last line ends in "…". It's fitted again when the screen changes size, e.g. a phone turned round.
    - The time left as mm:ss, e.g. "00:45". On each of a timed work step's **last 3 seconds** (for a step longer than that) the time pops in a little large and settles. Not rest. Countdown beeps tick in the last 3 seconds of timed steps and rests of 10 seconds or more (ALM-5; see [alarms](alarms.md)).)
    - On a rep step, the **count is the big thing**, e.g. "12 reps", with the weight and "Last time" under it.
    - During **rest**, just "Rest" (or the rest's name) and its time: what's after it is on the **Up next** card under the ring (below).
    - While paused, the face's text gives way to the step's name (a button for its details; in a rest before an exercise, "Rest, then Deadlift", for that one's), "Paused · 00:23", Resume and End workout (see [pause-and-stop](pause-and-stop.md)).
- **Moving on**: the face's text is on a drum behind the face, like the number wheels: the next step's text rolls up into view from below as the last one rolls away over the top, in perspective, on a spring with no bounce (about half a second), so a new step is plain to see. A step that comes before the last one has finished rolling in (a quick Done, say) turns the last one on away from wherever it had got to, rather than jumping it back to the middle first. When a new **round** starts the drum turns right to left instead, and the round line and dots above the ring turn with it; so does a step's next **set** (its round line as the set starts, after the rest). **Rest** settles in more gently: from a little way below, over most of a second, as the last step fades quickly away. The ring stays put. The text on its way out keeps showing the step it was, e.g. its last "00:01".
- **Your note** on the step's exercise (EXR-10), if you've written one, in a box under the ring, e.g. "Pause at the bottom". Any work or rep step linked to an exercise shows it; screen readers hear it with the step, e.g. "Push-ups, 20 reps, your note: Elbows in".
- **Up next** (since 2026-11-15, in place of the "Next:" line and the Done pill): a card under the ring on every step, so what's coming is easy to read from a step or two away while getting ready. It has the next step's **kind icon** in a disc and a border in its colour (pink for timed, blue for rest, violet for reps, the accent colour for finish), "**UP NEXT**", the **name big** on its own line, e.g. "Bench press", and the rest under it, e.g. "Set 2 of 3 · 12 reps @ 60 kg" or "00:45". Unnamed steps use their kind ("Timed", "Rest", "Reps"); before the last step it's "Finish", with a tick.
    - On a **rep step** it's **Done** (above), with the next exercise's name a button for its details.
    - Otherwise (a rest, a timed step, or any step while paused), when the next step is an exercise, the **whole card is a button** with an **(i)** at its end, opening that exercise's details with **Swap exercise** (RUN-11, below), to get ready for it or swap it before it starts; Skip is there to move on. After they close, focus is back on the card. When the next step isn't an exercise (a rest, or "Jog"), it's just the card. Screen readers hear "Up next: Bench press, Set 2 of 3 · 12 reps @ 60 kg", as a button that opens a dialog when it is one.
    - Paused, it steps back into the muted colour, still pressable.
- **What it says**: a step with sets says which, e.g. "Leg press", "Set 2 of 3 · 10 reps @ 40 kg", in the rest after the set before too. In a superset, only its first step says the round, as one starts ("Bench", "Superset round 2 of 3 · 10 reps"); the others are in the round already said ("Row", "10 reps"). A step's second side is only its side: "Right side", "10 reps", or "Right side", "00:30" during Switch sides.
    - In the **last 3 seconds** of a timed step or rest, as the countdown beeps tick (ALM-5), the card swells and glows in its colour once a second, to get ready. Each swell, and the face's flare with it, lands on the clock's second, in time with the countdown beeps, even when the pulse starts part-way through a second (on resuming, say). Not on a rep step, where it's Done instead (above), and not while paused.
    - In the same seconds the **face** flares to full colour on each second and eases back to its tint, in time with the card: one "get ready" cue, rather than a flash all step long.

### Changing reps or weight mid-workout (RUN-6)

- While a rep step is waiting, the **reps and weight on the face are wheels**: closed, each is just its number in the face's text, with a short faint line under it (no box) that says it can be changed, with its unit beside it ("reps", "kg"). Tapping one opens it there, over the ring, as wheels open anywhere else: **Reps** 1–100, and **Weight** none, then halves, in the unit chosen in You → Profile. No weight shows as "+", to add one. Screen readers hear them as spin buttons named "reps" and "Weight, kg". A stretch (thread the needle, the world's greatest stretch) has the reps alone, with no weight and no weight to try, as a stretch isn't loaded (since 2026-11-18).
- A change applies at once, to **this set, the rest of this workout's rounds, and the saved workout**, so next time starts from there; on a ready-made workout too (since 2026-11-08), which keeps your reps and weights as a record of its own (see [library](library.md)). If the workout has been deleted from the library meanwhile, only this workout changes.
- On a step whose sets vary (BLD-11), it applies to **this set only**, in this workout and the saved one: set 2 changed to 47.5 kg leaves sets 1 and 3 as they were. Each set's face shows its own reps and weight, and Up next during a rest says the next set's, e.g. "Leg press", "Set 2 of 3 · 10 reps @ 45 kg".
- On a step done each side, a change is for both sides of the set.
- A wheel closes by itself as it does anywhere else (on a pick, or two fifths of a second after it stops turning).
- Space on a focused wheel is left to the wheel, rather than pressing Done.

### Waiting for Start after a long rest (RUN-14)

- Since 2026-11-16, with **Wait for me after rests** on in Settings (the default), a **timed exercise straight after a rest of 30 seconds or more** doesn't start as the rest ends: it waits, at its full time, until **Start** is pressed. The rest between sets, between exercises or between rounds all count. Shorter rests, as in an interval circuit (Tabata's 10 seconds, a HIIT circuit's 20), run straight on, as do rep steps (which wait for Done anyway), the second side after Switch sides, and anything in a workout with a **time limit**, which is against the clock.
- While it waits, the face shows the exercise as it will start (its name, "00:45", the ring empty) with **Start** (▶ Start) under the time, so it's plain the exercise hasn't begun, and Space as its key. The big **Pause** button under the Up next card is greyed out meanwhile, as there's nothing yet to pause; Skip is beside it, and skips the exercise from its full time. Focus on Pause as the wait begins moves to Start, and pressing Start moves it to Pause. Start can also be pressed on the workout's bar on other pages, which says "Ready · Plank · 00:45". Screen readers hear the step as usual, then "waiting: press Start when you are ready". Until 2026-11-19 the ring filled while it waited, though the time held, and Start was the big button in Pause's place.
- **A workout that carries straight on after rests** never waits (BLD-18, see [build-a-workout](build-a-workout.md)): an interval circuit, whose rests are part of it rather than time to get ready. The ready-made **Tabata** and **Cardio intervals** do (since 2026-11-16), so Tabata's minute between moves and Cardio intervals' between rounds run straight on; the others wait before a hold or a carry after a long rest, e.g. Gym full body's plank and Dumbbell lower's farmer's carry.
- **Skipping the rest** before it says you're ready, so the exercise starts at once, without waiting.
- Nothing sounds while it waits: the exercise's own alarm and everything after it are booked only once Start is pressed, when the alarm sounds at once, as Done's next step's does. The rest's countdown beeps still count down to the wait.
- The time spent waiting is left out of the time spent, as a pause's is. Pausing while it waits, then resuming, goes back to waiting; Start from a pause starts it.
- The run keeps the setting as it was when it started, as with the each-side settings, so turning it off mid-wait can't move the clock; the next workout uses the new one. A reload carries on waiting.

### Changing the workout while it runs (RUN-15)

- Since 2026-11-16, saving the workout that's running in Create (its Edit, then **Save**) gives the run the change **from where it is**, when the change keeps it to the same clock: another exercise or name for a step, or other reps or weights. Sets already done stay as they were, under the exercise they were done as, as with a swap (RUN-11), and the summary doesn't offer the change to keep, as it's saved already. A step swapped mid-workout and then changed in Create runs as Create has it.
- A change that would move the clock (a step added, removed or moved, a time, or the sets or rounds) is saved **for next time**, and the run carries on as it was, a reload included.
- Its Details then say which, in the bar: "Saved. The workout that's going has the change from here." or "Saved for next time. The workout that's going carries on as it was.", each with **Back to workout**. Save & start workout starts it again from the beginning, as before.
- Until then the run kept the workout as it was when it started, until a reload, which picked up the saved one and could put the run's place, swaps and sets on the wrong steps.

### Swapping an exercise (RUN-11)

- The same swap is in Create, as each exercise step's **Swap** button (BLD-14; see [exercises](exercises.md)).
- **Swap exercise**, in the step's details (its name, on the face or while paused), opens "**Swap Back squat**". The Up next card's (i) (and, paused in a rest, "Rest, then …") opens the **next** exercise's details, so it can be swapped before it starts: the rest is when the machine's likeliest to be found taken. The swap dialog is over the workout: "For the rest of this workout. Sets done so far stay.", a **Search exercises** box (where focus starts), and a list.
- With nothing typed, the list is "**Same muscles**" ("Same muscles, with your equipment" once some is picked on the Exercises page): the **closest five**, each with its main muscles and equipment under its name, e.g. "Quads, glutes · Dumbbells", as the exercise picker shows them.
    - Only exercises **measured the same way** as the step (reps for a rep step, time for a timed one), as the step keeps its reps or time; not hidden ones, and not itself.
    - **A stretch only for a stretch**, and never a stretch for anything else: a cobra stretch works the abs, as a plank does, but isn't one to do instead of it.
    - Only ones that share a main muscle (one is enough; supporting muscles don't have to match), and that can be done with **your equipment**, if you've picked any (all of them if not). When none of them can be done with your equipment, e.g. only kettlebells for a chainsaw row, the closest five are offered whatever they need, under "**Same muscles, needing other equipment**", rather than nothing.
    - Ranked by how closely their main muscles match, each extra or missing main muscle counting against one (so a whole-body move doesn't top a chest one), a little for supporting muscles in common, and a little more for needing **none of its equipment**, as that's likely what's taken. Then by name.
    - With none, "Nothing else works the same muscles. Search for one above."
- Typing searches every exercise measured the same way by name, as the picker does (hidden ones only when named in full), under "3 matches"; with none, "No exercise measured in reps matches that."
- An exercise that's **in the workout already**, as another step or a swap, says "Already in this workout" under its name (since 2026-11-16). It can still be picked, as doing one twice is often meant.
- Picking one swaps the step **for the rest of this run**: its name and exercise are the new one's; its reps or time, sets (and how they vary) and sides stay; its **weight is the new exercise's from last time** (each set's own where they vary), or none if it's never been done with a weight. The (i), Last time, the step up to try and your note follow the new exercise.
- The Undo bar says "**Swapped to Goblet squat**", with **Undo** to put the step back, until the step ends (then it goes, rather than sitting over Pause); swapped from the rest before it, through that rest and the step. Focus goes back to the (i).
- **Sets already done stay as they were**, under the old exercise, timed ones included; the history logs each set as the exercise it was done as, so progress, personal bests and the muscles worked count the right one.
- **The saved workout keeps its own**: changing the reps or weight of a swapped step changes it in this run only. A step can be swapped again, or back.
- The swaps are kept for the tab, so a **reload** carries on with them; a new run starts with none.
- ✕, Escape or a tap outside close it, swapping nothing, with focus back on what opened the details (the name or the Up next card). Space and Escape are left to the dialog while it's open.
- If the step ends while the dialog is open (a timed step running out), picking swaps nothing, and the Undo bar says "Back squat has finished, so it wasn't swapped". If the rest ends while the next one's is open, picking swaps it, now it's started.

### Finishing, and the summary (RUN-4, RUN-7)

- The face says "**You're finished!**", the controls go, and the **summary** opens over the page by itself. End workout opens the same summary (see [pause-and-stop](pause-and-stop.md)).
- It's a sheet: the whole screen on a phone, a card in the middle on anything wider. Focus starts on its heading and stays inside it.
- It **rises in** on a spring with no bounce (from the bottom of the screen on a phone, a little way on a wider one) as the page behind dims, and **sinks back out the same way** when it closes.
- On a phone, a workout ended early can be **dragged down** by the grabber at the top of the sheet to go back to it, as Back to workout does; while it's scrolled to the top, its heading and title drag it too. The sheet follows the finger, resists being pulled up, and the page behind brightens as it goes. On letting go, where the flick would carry it decides: past halfway it carries on down at the finger's speed and goes back to the workout; short of that it springs back up, with a little bounce if it was flicked. It can be grabbed again mid-spring, even on its way down, and then it stays; grabbed anywhere on it as it rises in and just held, it carries on up. Closed with Back to workout, Escape or Done, it sinks back down from wherever it is (on a wider screen, where it's a card, it drops a little as it fades). A finished workout has no grabber, as there's nothing to go back to. Every dialog is a sheet on a phone that drags the same way (`SheetDrag`, `src/app/shared/sheet-drag.ts`).
- It fits the screen however much it shows: its content scrolls, with the buttons always in reach under it.
- It shows:
    - "**Workout finished**", "**Time's up**" (a time limit that ran out) or "**Workout ended**", and the workout's title.
    - **Time** (as in the history, pauses left out) and **Rounds**, e.g. "1 of 3 rounds · stopped", or "7 rounds + 3 in 20:00" for a time limit. With a body weight given, a third, **Calories**: "About 210 kcal", heard as "about 210 calories" (CAL-1, since 2026-11-14; see [calories](calories.md)) Without one, **Add your weight to see calories** under them, which ends the run and opens You with focus in Body weight (CAL-2).
    - **Personal bests** this workout set (PRG-2), and "Most rounds: 7 rounds + 3" for a time limit beaten (PRG-7; see [progress](progress.md)).
    - **Sets**, one line per step as in the history, e.g. "Squats: 10, 10, 8 @ 60 kg" or "Plank: 3 × 0:45".
    - **Next time**: a step up for each rep step where every set got its reps, and each timed exercise where every set ran its whole time, e.g. "Bench press: try 82.5 kg, up from 80 kg", "Push-ups: try 13 reps, up from 12" or "Plank: try 35 seconds, up from 30 seconds", each with **Apply** to put it on the saved workout (PRG-10). Not for a swapped step (RUN-11), whose saved step is still the old exercise, unless it's been kept.
    - **Swapped** (RUN-11): each step swapped, e.g. "Back squat for Goblet squat", and "Use Goblet squat next time?" with **No, just this time** and **Yes, use next time** (for a workout still in the library). Yes puts the swapped step (its exercise, name and weight) on the saved workout and says "Saved: next time it's Goblet squat."; No leaves it, saying "Next time it's Back squat again.", as the machine's likely free next time. Focus moves to what it says. A step swapped back to what it was isn't listed.
    - **Muscles worked**: the body map, shaded by this workout's sets (PRG-11).
    - A **Note** box, saved to this workout in the history as you leave it.
    - The **suggested next workout**, as on Today, only the best and without its Start button (PRG-9; see [progress](progress.md)).
    - Buttons: **Stretch what you worked** (the main one, when there are stretches to offer, PRG-16, since 2026-11-19), **Done** (the main one otherwise: on to the history, with this workout highlighted), and **Back to workout** for a workout ended early or one that runs until stopped. Escape does the same as Back to workout, where there is one.
- **Change reps or weight** (shown when there are rep sets) makes each rep exercise's line a button (✎), still grouped as the lines are: under the workout's headings, and a superset's steps together under "Superset" (or "Giant set"). Pressing one opens a dialog of that exercise's sets, "Set 1", "Set 2" ("Set 1, left" for one done each side), each with a Reps and a Weight wheel, and **Save**, so a set logged wrongly can be corrected (e.g. the last set was 8, not 10). One exercise at a time, as a whole workout's wheels at once was too much for a phone. ‹ Back, Escape or a click outside close it changing nothing, with focus back on its line; saved as it was, nothing is asked. **Done changing** puts the lines back. Timed sets ran as set, so they can't be changed. A change goes into this workout's history entry at once, and then asks "**Use these settings next time?**":
    - **Yes, use next time**: each rep step of the saved workout starts next time from its sets in this workout, each set as it was last done (both sides as one) and any not done as it was. Sets that came out the same stay one Reps and Weight; sets that differ turn on Vary each set (BLD-11), so a pyramid worked out mid-workout is kept. A step given a Next time step-up with **Apply** keeps the step-up instead, before or after Yes. It says "Saved: next time starts from these.", adding ", with the step-ups you applied" when there are any.
    - **No, just this time**: only the history changes.
- A workout ended before its first step was done has nothing logged: the summary says "Nothing to log", with no note box. Done still goes to the history.
- The workout is logged in the history once, when it finishes, wherever the user is in the app (see [history](history.md)). It's dated when it actually finished, even if the app only noticed later.

### The tour of the workout page (RUN-13)

- **Shown once, on the first workout run on a device**: one with nothing in its history, so a device already in use, or one signed in with its history synced, doesn't get it. Only as a workout starts (from any Start button), not for a run picked up after a reload or opened from the run bar, and not while another tour is on. It's kept on the device only (`tour-workout`, see [data](data.md)).
- **The clock waits for it.** The page shows the first step as it looks running, with Pause and Skip, not Resume and End workout, but its time stands still and no alarm sounds till the tour ends, however it ends (Done, Skip tour or Escape). A reload while it's on carries on paused.
- It's the tour of the app's overlay and card (see [home and navigation](home-and-navigation.md#the-tour-nav-8)), staying on the workout and lighting up no tab: **six stops**:
    1. **The workout**: the bubble, saying the clock waits till you're done, and that its ring fills as a timed step's time goes.
    2. **What's next**: the line under the bubble, and that it pulses as the step nears its end.
    3. **Rep steps**: the reps and weight, to change to what you did, then the line under the bubble to press when done (RUN-3, RUN-6).
    4. **How it's done**: tapping the exercise's name, with Swap exercise there (RUN-9, RUN-11).
    5. **Pause and skip**: Pause, with End workout behind it, and Skip (RUN-12).
    6. **Off you go**: the workout carries on on other pages, with the run bar to come back (CTL-4); Done carries on.
- A stop whose part isn't on the step it's on, e.g. the reps on a timed step or the exercise's name on an unnamed one, says it in words and lights up nothing.
- **Done and Skip tour both leave focus on Pause**, ready for the clock that's just started.
- **Running a workout, in Help's Tours** (since 2026-11-09), takes it again any time:
    - **With a workout going**, it opens the workout page on it with the tour, holding its clock the same way. As the tour ends, the run carries on as it was: running, or still paused, with focus on Resume. With End workout pressed and the summary open, it opens the summary, with no tour.
    - **With none**, it starts a **practice run of Bodyweight basics** (no kit, and a rep step first, so every stop has its part), whose first stop is **A practice run** ("just for the tour: the clock waits, and nothing's logged") and last **That's it** ("Done ends this practice run and goes back to Help"). As the tour ends, however it ends, the run's stopped, logging nothing (a run stopped before any step is done leaves no trace), and Help is back with focus on Running a workout.
    - Either way it counts as seen, so a first workout after it shows no tour.
- The ? beside Tap to turn on sound stays: it's about sound after a reload, which the tour doesn't cover.

### No workout

- The workout page with no workout running says "No workout selected." with a link, "Choose a workout" (until 2026-11-08 "Choose one from your workouts": Workouts has the ready-made ones too now).

- Given the same, when I skip the rest, then the plank starts at once; when I press Skip while it waits, then it's skipped from its full time.
- Given Tabata, when its minute's rest between moves runs out, then the next move starts at once, as it carries straight on after rests.
- Given Wait for me after rests turned off, then nothing waits; given it's turned off while a plank waits, then that run still waits for Start.
- Given a run of Plank then rest, twice, a second into round 2, when the workout is saved in Create with Side plank for Plank, then the run says Side plank, round 1's set is logged as Plank and round 2's as Side plank, the summary offers no swap to keep, and its Details say "Saved. The workout that's going has the change from here."
- Given a run, when the workout is saved in Create with a step added, then the run carries on as it was, a reload too, and its Details say "Saved for next time. The workout that's going carries on as it was."
- Given Push-up then Diamond push-up, when I press Swap on Push-up and search "diamond", then Diamond push-up says "Already in this workout", and can be picked.

## Platform notes

- **Web:** the maths is pure and has no Angular in it, so it can be ported line for line: `workoutStateAt()` in `src/app/models/workout-state.ts` (where a workout is after so many ms, given the rep steps done and, for a time limit, the time off the clock: the time rep steps took, less any time skipped; `stepsIntoRound()` gives the score's steps) and the helpers in `src/app/models/workout.ts`. The run itself is `ActiveRunService` (`src/app/shared/run/`), and the page is `WorkoutComponent` (`src/app/workout/`), with what it shows worked out in `WorkoutView` (`workout-view.ts`), a step's text on the face in `workout-face-slide/`, the round line in `workout-round-line/`, details and swapping in `WorkoutSwap` (`workout-swap.ts`), each kind of step's look and motion in `workout-steps.scss` and `workout-motion.scss`, the step strip in `step-strip/`, an exercise's details in the shared `ExerciseDetailsDialogComponent` with `brief` (RUN-9), and long names fitted to the face by `fitName()` (`fit-name.ts`), which measures the text rather than counting letters.
- **Web:** waiting for Start (RUN-14) is `nextWait()` in `src/app/models/wait-to-start.ts`, which `ActiveRunService` holds its clock at (`elapsedMs` stops at the wait, as `workoutStateAt()` stops at a rep step) until `startExercise()` moves the start time on by the wait (`WorkoutStore.passWait()`), as Done does; Start in the face is `WaitStartComponent` (`src/app/workout/wait-start/`), which also moves focus, and the ring's fill isn't there while it waits (`WorkoutView.ringSweep`); the alarms past it aren't booked till then. A change in Create to the workout running (RUN-15) is `ActiveRunService.takeEdit()`, with `canTakeEdit()` and `editSwaps()` in `src/app/models/run-edit.ts`: an edit becomes swaps marked `edited`, which `withSwaps()` runs as the workout has them, so the sets before stay as they were. The store keeps the workout as the run has it (`activeWorkout` in the tab), for a reload.
- **Web:** doing a skipped exercise later (RUN-16) is `src/app/models/later.ts`: `ActiveRunService` keeps the clock with `laterAt()`, which holds it at the queue's place (`LaterQueue.atMs`, once `repStepsDone` are done) while a step done later runs, so `clockState` is where the workout is and `state` the step on now (with `later: true`, and its own round and place, so its set logs there). A timed one is taken off the queue as it runs out (`laterRunOut()`, in `sync()`), moving the start time on by its length, as Done does; `withLaterAlarms()` books its alarms and moves the rest on. The presses, putting aside on Skip and picking, are `LaterPicks` (`src/app/workout/later-picks.ts`, with `models/later-pick.ts`), beside the page rather than in the run, which every page downloads; the button and menu are `LaterListComponent`, whose flights, in from the ring and down to the Up next card, are `flyInto()` and `flyOnto()` (`later-fly.ts`). The copy flies in the list's host, which stays while the button may go. The Undo bar's offer goes with the next press as it's `untilNextPress` (`UndoOffer`). Saved as `activeLater` (see [data](data.md)). At the end, `ActiveRunService.askingFinish` holds the run short of finished (`isComplete` waits for it) while any are put aside; `FinishLaterDialogComponent` asks, its list in `FinishLaterListComponent` (a CDK drop list, with `LaterPicks.move()` and `moveAside()`), and `LaterPicks.doBeforeFinish()`, `doAllBeforeFinish()` (`pickAllAt()`) and `finish()` answer with `ActiveRunService.leaveFinish()`, which puts the clock back at the end (`WorkoutStore.passHeld()`), the one picked queued there with `pickAt()`.
- **iOS:** the same queue held on the clock; the button is a toolbar item with a `.badge`, opening a `Menu`.
- **Web:** the summary is `WorkoutSummaryComponent` (`src/app/workout/workout-summary/`), with its sets in `SummarySetsComponent` and Next time in `SummaryStepUpsComponent`. Swapped is `SummarySwapsComponent`. Its host is a grid whose one cell is the screen (`grid-template: minmax(0, 1fr) / minmax(0, 1fr)`): an auto row grows to the content, and the sheet then runs off the screen once the summary is long.
- **Web:** the tour of the workout page (RUN-13) is `TOURS.workout` in `src/app/tour/tour-stops.ts`, started by `tourWorkoutPage()` (`src/app/workout/workout-tour.ts`), which the page calls as it opens: on a first workout, or with `?tour=run` or `?tour=practice` in the address, which Help's `tourOfWorkout()` opens it with (and the page takes off again). The practice run's tour is `TOURS['workout-practice']`, the same stops with its own first and last. It holds the clock with `ActiveRunService.hold()`, which pauses the run in the store but sets `held`, so `WorkoutView.isPaused` stays false and the page looks as it does running; `release()` resumes it as the tour ends, or as the page closes, unless it was paused before. Resume has the id `workout-resume`, for focus after a paused run's tour. The parts it lights up have `data-tour` attributes (`stage`, `next`, `reps` round both wheels, `info`, `controls`), and Pause has the id `workout-pause` for focus at the end.
- **iOS:** keep the same "work it out from the clock" design: store when the run started (moved on by pauses and rep steps, back by skips) and derive everything else. The face's drum is a `rotation3DEffect` about the x axis (the y axis for a new round) with an anchor behind the face; a long name can use `ViewThatFits`, or `lineLimit(3)` with `minimumScaleFactor(0.7)`. The (i) by an exercise's name (RUN-9) can open its details as a `.sheet` with medium and large detents, so the ring stays in sight above it. The tour of the page (RUN-13) would be the same overlay as the other tours, or a `TipGroup` of TipKit `.popoverTip`s, with the run's clock paused but not shown paused.
